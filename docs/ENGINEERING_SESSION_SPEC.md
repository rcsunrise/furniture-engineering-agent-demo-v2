# Engineering Session Specification (G4-SYSTEM-AUDIT-01)

## Overview
The `EngineeringSession` is the single canonical runtime context for the Furniture Engineering Agent. It unifies Reference Images, AI Inference, Local Worker GLB Artifacts, FES Engineering Documents, Component Artifact Bindings, Mesh Alignment, and Production Eligibility Gates.

---

## Data Model Specification (`src/shared/engineeringSession.ts`)

```typescript
export interface EngineeringSession {
  id: string;
  workspaceId: string;
  sku: string;
  status: EngineeringSessionStatus;

  referenceImageArtifactId?: string;
  aiMeshArtifactIds: string[];
  fesDocumentId?: string;
  activeComponentId?: string;

  componentBindings: ComponentArtifactBinding[];
  alignmentSessions: string[];

  diagnostics: EngineeringPipelineDiagnostics;

  productionTruth: boolean;
  createdAt: string;
  updatedAt: string;
}
```

---

## Key Lifecycle States (`EngineeringSessionStatus`)

1. **`created`**: Session initialized with SKU and workspace ID.
2. **`image_ready`**: Reference image uploaded and bound to session.
3. **`mesh_ready`**: AI Mesh generated by Local Worker and registered.
4. **`fes_ready`**: FES document parsed or drafted and bound to session.
5. **`alignment_ready`**: AI Mesh normalized and aligned to FES component coordinate system.
6. **`geometry_ready`**: Component geometries evaluated for CAD / 3D rendering.
7. **`assembly_ready`**: Full 3D assembly scene verified in viewport.
8. **`validated`**: Engineering validation rules evaluated.
9. **`production_candidate`**: All components verified with `productionTruth = true`.
10. **`blocked`**: Unresolved binding or critical validation error.

---

## Binding Engine (`resolveComponentBinding`)
Converts an incoming AI artifact into a `ComponentArtifactBinding` mapped to a specific FES component.
- **Strict Matching:** Maps `partId` to `componentId`.
- **Ambiguity Guard:** Returns `UNRESOLVED_BINDING` if partId matches 0 or >1 components. Never assigns silent false bindings.
- **Truth Integrity:** Sets `productionTruth = false` for all AI-generated mesh bindings.

---

## Production Gate (`isProductionEligible`)
Evaluates session readiness:
- **`DISPLAY_READY`**: Renderable in 3D viewport using box/soft proxy geometries. `productionEligible = false`.
- **`ENGINEERING_READY`**: Renderable with AI mesh guidance or parametric drafts, but lacks verified CAD B-Rep truth. `productionEligible = false`.
- **`PRODUCTION_READY`**: 100% of components verified with CAD engineering specifications and `productionTruth = true`. `productionEligible = true`.
